A fully functional, high-performance 3D sandbox game in the browser, built completely from scratch! **TipeCraft** features a massive, procedurally generated voxel world with endless possibilities for building, exploring, and surviving.

The project is cross-platform optimized and runs smoothly in web browsers, as a Windows application, and on Android smartphones (fully responsive with custom touch controls).

### 🚀 Features
- **Procedural World Generation:** Endless hills, valleys, and landscapes based on mathematical noise algorithms (perfectly playable up to a limit of 1,250,000 blocks!).
- **Massive Variety:** Over 226 different blocks and 10 unique biomes to discover.
- **Living World:** Fully functional day/night cycle, mobs (creatures), and an integrated crafting system.

- **Cross-Platform:** Optimized controls for keyboard/mouse (PC) and dynamic touch overlays for mobile devices.

### 🛠️ Roadmap (Upcoming Features)
- [ ] **User Accounts (Cloud Save):** Optional accounts to save up to 2 worlds in the cloud.
- [ ] **Real-Time Multiplayer:** Build together with friends using WebSockets.
- [ ] **Custom Server Hosting:** Connecting to servers via unique `.tc` addresses (using a hybrid hosting model for small and large servers).
- [ ]  **Custom Save System:** Worlds are saved using a custom-built, highly efficient file format (`.tipeworld`).
- [ ]   **Worldborder Safety:** A built-in protective barrier at 1,250,000 blocks protects the game from floating-point graphical glitches (can be disabled in options with a warning note).

### 🎮 Controls
#### PC (Keyboard & Mouse)
- `W` `A` `S` `D` – Move
- `SPACE` – Jump
- `SHIFT` – Sneak / Descend
- `LEFT MOUSE BUTTON` (LMB) – Mine block
- `RIGHT MOUSE BUTTON` (RMB) – Place block
- `1-9` – Hotbar selection

#### Mobile (Smartphone & Tablet)
- Dynamic on-screen touch buttons for movement and actions.

Ein voll funktionsfähiger, performantes 3D-Sandbox-Spiel im Browser, komplett von Grund auf selbst programmiert! **TipeCraft** bietet eine riesige, prozedural generierte Voxel-Welt mit unzähligen Möglichkeiten zum Bauen, Erkunden und Überleben.

Das Projekt ist plattformübergreifend optimiert und läuft flüssig im Webbrowser, als Windows-Applikation und auf Android-Smartphones (vollständig responsive mit Touch-Steuerung).

### 🚀 Features
- **Prozedurale Weltgenerierung:** Endlose Hügel, Täler und Landschaften basierend auf mathematischen Noise-Algorithmen (spielbar bis zu einer Grenze von 1.250.000 Blöcken!).
- **Riesige Vielfalt:** Über 226 verschiedene Blöcke und 10 einzigartige Biome zum Entdecken.
- **Lebendige Welt:** Funktionierendes Tag/Nacht-System, Mobs (Kreaturen) und ein integriertes Crafting-System.
- **Eigenes Speichersystem:** Welten werden in einem eigens dafür entwickelten, hocheffizienten Dateiformat (`.tipeworld`) gesichert.
- **Sicherheits-Barriere (Worldborder):** Eine integrierte Schutzwand bei 1.250.000 Blöcken schützt das Spiel vor Floating-Point-Grafikfehlern (kann in den Optionen mit Warnhinweis deaktiviert werden).
- **Cross-Platform:** Optimierte Steuerung für Tastatur/Maus (PC) sowie dynamische Touch-Overlays für Mobilgeräte.

### 🛠️ Geplante Features (Roadmap)
- [ ] **Nutzerkonten (Cloud-Save):** Optionale Accounts zum Speichern von bis zu 2 Welten in der Cloud.
- [ ] **Echtzeit-Multiplayer:** Gemeinsam mit Freunden über WebSockets auf Servern bauen.
- [ ] **Eigenes Server-Hosting:** Einbindung von Servern über einzigartige `.tc`-Adressen (mit hybridem Hosting-Modell für kleine und grosse Server).

### 🎮 Steuerung
#### PC (Tastatur & Maus)

- `SHIFT` – Schleichen / Sinken
- `LINKE MAUSTASTE` (LMB) – Block abbauen
- `RECHTE MAUSTASTE` (RMB) – Block platzieren
- `1-9` – Hotbar-Auswahl

#### Mobile (Smartphone & Tablet)
- Dynamische Touch-Buttons auf dem Bildschirm für Bewegung und Aktionen.
