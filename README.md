## 🗺️ Allgemeines & Spielwelt
*   **Plattform:** Direkt spielbar im Webbrowser via Replit, optimiert für PC (Tastatur/Maus) und Mobilgeräte (Touch-Steuerung).
*   **Weltgröße:** Die prozedural generierte Welt ist dank sauberer Optimierung bis zu einer Grenze von **1.250.000 Blöcken** stabil spielbar.

---

## 🔨 Crafting-Rezepte
Das Crafting-System ermöglicht die Transformation von Rohstoffen:
*   **Planks (Holzbretter):** Werden aus rohen Baumstämmen (*Logs*) hergestellt.
*   **Craftingtable (Werkbank):** Wird aus vier *Planks* gecraftet.
*   **Kiste & Ofen:** Werden über ein **Rand-Rezept** (Blöcke als Ring angeordnet) hergestellt. 
    *   *Hinweis:* Die Kiste ist voll funktionsfähig. Der Ofen kann platziert werden, die Schmelzlogik folgt im nächsten Build.

## 📦 Blöcke & Dimensionen
Im Kreativinventar befinden sich bereits über **226 verschiedene Blöcke**, die schrittweise in die Weltgenerierung eingebaut werden:
*   **Erze:** Werden zusammen mit der Ofen-Funktion in den kommenden Updates unterirdisch generiert.
*   **Nether-Blöcke:** Bereits im Code integriert. Sie dienen als Vorbereitung für das zukünftige **Dimensions-Update**.

## 🐛 Bekannte Fehler & UI (Bug-Tracker)
*   **Zahlen-Freeze Bug:** Wenn in Chat-Commands (wie `/tp`) oder Eingabefeldern eine viel zu große Zahl eingegeben wird, kann die JavaScript-Engine die Berechnung nicht mehr verarbeiten. Das gesamte Spiel friert daraufhin ein und stürzt ab. *(Bitte vorerst nur normale Koordinaten nutzen!)*
*   **Taste `E`:** Öffnet aktuell noch ein veraltetes, verbuggtes Inventar. Dieser Fehler wird im **nächsten großen Build** komplett behoben.
*   **Inventar-Steuerung:** Das fehlerfreie Hauptinventar öffnet sich standardmäßig mit der Taste `I`.
*   **Mobile Flug-Bug:** Wenn man auf Mobilgeräten im Kreativmodus aufhört zu fliegen und den Boden berührt, kann man danach über die Touch-Steuerung nicht wieder abheben.
*   **Kreativmodus-Mob-Bug:** Mobs versuchen fälschlicherweise, den Spieler im Kreativmodus anzugreifen. Sie machen dabei aber keinen Schaden.
